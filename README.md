# 🏦 Bank Branch Performance Analysis

## 📌 Project Overview
A data analytics portfolio project built using Microsoft Power BI and Microsoft Excel to explore bank branch performance and support data-driven business decisions.

## 🎯 Objectives
- Organize and analyze bank branch performance data.
- Present data through interactive Power BI visualizations.
- Make performance patterns easier to explore and communicate.
- Support business reporting and decision-making.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** — Dashboard development and data visualization
- **Microsoft Excel** — Dataset and source data management

## 📂 Project Files
| File | Description |
|---|---|
| `bank branch performance overview.pbix` | Power BI dashboard |
| `Bank_Branch_Performance_Dataset.xlsx` | Excel source dataset |

## 🚀 How to Run
1. Download both files from this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. If prompted, update the Excel source file path.
4. Refresh the data if required.
5. Explore the dashboard and available report interactions.
